# Codex

When a real economic phenomenon first appears in a playthrough (merchants flood a port and crash the price, say), a small window opens. It explains the concept in the game's own language, gives its real name and source, and leaves a strategic hint: "This is a pork cycle. Entering while everyone else leaves can pay."

The codex is written **as the simulation produces the phenomena**, not before. Every entry below appeared in an experiment without being scripted. Each concept is someone else's discovery, and its source is given. What the simulation adds is evidence that the mechanisms are wired correctly, plus numbers to calibrate against.

Each page has four parts: **literature → mechanism in the model → what appeared in the simulation → player text.**
